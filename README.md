# 开题报告与答辩 Skill

用于准备研究生开题报告、开题答辩PPT及逐页讲稿，将业务场景、研究问题、目标、方法机制与验证安排逐项对应。

## 包含内容

- `SKILL.md`：开题论证、报告结构、PPT篇幅、文献与格式、交付验证要求。
- `agents/openai.yaml`：技能名称、默认提示及自动选用配置。
- `references/开题报告和开题答辩PPT要求.txt`：用户提供要求的UTF-8整理副本。

原始要求中的历史日期和文献年份是示例。实际进度、文献窗口及学校栏目以当前材料为准。

## 安装

将仓库根目录保存到Codex个人技能目录下的 `kaiti-proposal` 文件夹，例如：

```powershell
git clone https://github.com/Tency-star/kaiti-proposal.git "$env:USERPROFILE/.codex/skills/kaiti-proposal"
```

如果目标目录已存在，先检查已有版本再合并更新。启动新会话后可直接调用：

```text
使用 $kaiti-proposal，根据我的最新开题报告和学校模板制作开题答辩PPT初稿。
```

## 输入与工具

提供最新研究题目、开题报告、学校模板及已完成工作的实际证据。没有材料支持的实验数值与成果状态不能编造。

制作PPT需另行准备已安装的 `ppt` 技能，优先使用其Markdown入口生成可编辑PPTX，再通过PPTX工具调整复杂框图。该技能来源为 [魔搭 @cyangzhou/ppt](https://modelscope.cn/skills/@cyangzhou/ppt)。Word排版需配合DOCX技能，文献核对需能访问原始论文与官方标准。

本技能保留原始提供者的Word格式偏好，包括只使用模板已有样式、宋体正文、黑体标题、英文数字Times New Roman、自动标题编号与题注。用于其他学校时，按当前用户要求和官方模板调整。

## 质量要求

研究内容通常组织为3至4项，每项对应关键问题、方法框图、直接基线、消融与验收指标。PPT含封面、提纲、背景、现状、目标与内容、方案、候选创新、计划、成果形式、文献和总结，逐页标页码，并渲染检查。

本技能用于写作与答辩准备。学校提交、共享权限变更及外部发布需按当前用户授权执行。
